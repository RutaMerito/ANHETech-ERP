# ANHETech ERP™

Sitio corporativo institucional de ANHETech ERP™.

## Descripción

Proyecto independiente para la presencia digital corporativa de ANHETech ERP™, una empresa colombiana de ingeniería de software y tecnología.

## Estructura

- `index.html` — página principal
- `styles.css` — estilos visuales
- `script.js` — interacciones y menú
- `assets/images/` — recursos oficiales

## Desarrollo local

Ejecutar desde la carpeta del proyecto:

```bash
npx serve .
```
